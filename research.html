Open-Source Software & Datasets

Framework

GRETEL

Graph Counterfactual Explanation Evaluation Framework. An open-source platform for developing and testing GCE methods with built-in datasets, models, and evaluation metrics.

View on GitHub
Framework

ERASURE

Machine Unlearning framework with extensible components for custom unlearning techniques, synthetic datasets, evaluation metrics, and ML model integration.

View on GitHub
Dataset

CLAIRE COVID-19 Dataset

A multi-source biomedical network integrating clinical evidence on COVID-19 with genomic and proteomic data for relational and graph-based learning methods.

View on GitHub
Dataset

MNIST4OD

Large-scale dataset suitable for Outlier Detection tasks, based on the MNIST dataset, with controlled outlier ratios for benchmarking anomaly detection methods.

View on Figshare
Dataset

Wiki-MID

LOD-compliant multi-domain interests dataset with ~500K Twitter users and 90 average preferences per user across music, books, movies, sport, politics, and more.

Access Dataset
Library

G

Fast and memory-efficient Graph Library for Graph Mining in Java. Manages weighted directed/undirected graphs with PageRank, HITS, and concurrent multithread algorithms.

View on GitHub
Tool

uCrawler

Universal Crawler — a concurrent, distributed, highly configurable, and flexible next-generation web crawler with REST services support.

View on GitHub
Contributor

Terrier IR

A highly flexible, efficient, and effective open-source search engine developed at the University of Glasgow. Giovanni Stilo contributed to identifying and solving several issues.

Terrier.org
